## AI-CITE

I follow the AI-CITE framework for improving AI-related SEO:

- **A:** Answer first ("in short", etc);
- **I:** Intent-matched headings (explicit, verbose headings);
- **C:** Clear structure;
- **I:** Indexed schema (Quarto does this automatically with the markdown schema header);
- **T:** Trusted sources (include references);
- **E:** Exclusive POV (fancy unique concepts or frameworks - this one I don't like much).
